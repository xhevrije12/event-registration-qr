LOG #09 — Vercel Deployment Debugging (VITE_API_URL)
Date: May 2026
Tool: Claude (Anthropic)
--------------------------------------------------------------------------------

PROMPT:
"My Vercel frontend is still calling localhost:5000 even though I set
VITE_API_URL in Vercel environment variables. What's wrong?"

AI HELP RECEIVED:
- Explained that Vite bakes env vars at build time, not runtime
- If the build ran before the env var was added, it uses the fallback
- Two solutions offered:
  1. Add .env.production file to client/ and commit it
  2. Use a hardcoded fallback URL directly in api.js
- Also identified that the Vercel root directory must be set to 'client'
  and framework preset must be 'Vite'

WHAT I IMPLEMENTED:
Changed the fallback in api.js from 'http://localhost:5000' to
'https://cinecloud-api.onrender.com' so even if VITE_API_URL is missing
from the build, the correct backend URL is used.
